## 시스템 `확인됨`

| 항목 | 값 |
|---|---|

| 형태 | 단일 Spring Boot WAR (SPA 내장) |
| 노출 포트 | 8080 |
| 프로토콜 | HTTP (**HTTPS 강제 설정 없음**) `미결정` |

## 사용자 `확인됨`

### 비회원 방문자

| 항목 | 내용 |
|---|---|
| 인증 | 없음 (`CustomUserDetails`가 `null`) |
| 가능 | 게시판 목록, 자유게시판 읽기·쓰기, **파일 업로드·다운로드** |
| 불가 | Q&A·자료실, 댓글, 좋아요, 마이페이지 |
| 식별 | 글 작성 시 `guestNickname` + `guestPassword` |

**파일 업로드가 가능한 것은 의도치 않은 노출로 보입니다.**
`POST /api/files`가 `permitAll`이고 도메인 판정도 없습니다. `미결정`

### 회원

| 항목 | 내용 |
|---|---|
| 인증 | 세션 쿠키 (`JSESSIONID`) |
| 상태 | `PENDING` 또는 `ACTIVE` 모두 로그인 가능 |
| 가능 | 모든 게시판, 댓글, 좋아요, 마이페이지 |
| 제한 | 자기 글·댓글만 수정·삭제 |

### 관리자

| 항목 | 내용 |
|---|---|
| 역할 | `MemberRole.ADMIN` |
| 가능 | 모든 글·댓글 수정·삭제 |
| **전용 화면** | **없음** |
| **계정 생성 경로** | **없음** — DB 직접 수정만 가능 `미결정` |

## 외부 시스템 `확인됨`

### SMTP 제공자

| 항목 | 값 |
|---|---|
| 기본 설정 | 네이버 메일 (`smtp.naver.com:465`, SMTPS) |
| 대안 | 587 + STARTTLS (`MAIL_SMTP_SSL=false`, `MAIL_SMTP_STARTTLS=true`) |
| 인증 | `MAIL_USERNAME` + `MAIL_PASSWORD` (앱 비밀번호) |
| 호출 방향 | 시스템 → 제공자 (아웃바운드만) |
| 호출 시점 | 트랜잭션 커밋 후 비동기 |
| 타임아웃 | 연결·읽기·쓰기 각 5초 |

**미설정 시 폴백**: `MAIL_SMTP_HOST`나 `MAIL_USERNAME`이 비면
`LoggingMailSender`가 본문을 로그로만 남깁니다 (`config/MailConfig.java:39-45`).

**발송 종류 3가지**
- 이메일 인증: `{APP_BASE_URL}/verify-email?token=...`
- 비밀번호 재설정: `{APP_BASE_URL}/find-password?token=...`
- 아이디 찾기: 아이디 평문 + 로그인 링크

### CAPTCHA 제공자

| 항목 | 값 |
|---|---|
| 호출 방식 | HTTP POST (JSON), `java.net.http.HttpClient` |
| 요청 본문 | `{ secret, response, remoteip }` |
| 성공 판정 | 응답의 `success` 필드 |
| 타임아웃 | `CAPTCHA_TIMEOUT` (기본 3초) |
| 사용 시점 | 회원가입, 비밀번호 재설정 요청 |

**provider가 확정되지 않았습니다.** `plan.md` 선결 결정 #1.
현재 기본값은 `mode=fake`로, 고정 문자열 `dev-captcha`만 통과시킵니다. `미결정`

요청·응답 형식(`secret`/`response`/`remoteip`, `success`)은 reCAPTCHA·hCaptcha 계열과
호환되는 모양이지만, JSON 본문으로 보냅니다
(이들 서비스는 보통 form 인코딩을 요구합니다). 실제 provider 연동 시 확인이 필요합니다. `미결정`

### PostgreSQL

| 항목 | 값 |
|---|---|
| 버전 | 15 (alpine 이미지) |
| DB명 | `board_db` |
| 계정 | `board_user` |
| 스키마 관리 | Flyway V1~V4 |
| Hibernate DDL | `validate` (자동 생성 안 함) |
| clean | **비활성화** (`clean-disabled: true`) |

DB 주소는 환경마다 다릅니다.

| 환경 | 결정 방법 |
|---|---|
| 로컬(분리 실행) | `.env`의 `PGSQL_HOST`/`PGSQL_PORT` |
| 컨테이너 | `SPRING_DATASOURCE_URL` 환경 변수가 통째로 덮어씀 |
| 기본값 | `192.168.29.124:5432` (줄이 아예 없을 때) |

## 시스템 경계 밖 `확인됨`

아래는 이 시스템이 하지 않습니다.

| 항목 | 상태 |
|---|---|
| TLS 종단 | 리버스 프록시 전제로 보이나 구성이 문서화되지 않음 `미결정` |
| 파일 저장소 | 외부 오브젝트 스토리지 미사용. 로컬 볼륨 |
| 세션 저장소 | 외부 저장소 미사용. 인메모리 |
| 로그 수집 | stdout만 |
| 인증 위임 | OAuth·SSO 없음 |
| CDN | 없음 |
| 검색 엔진 | DB `LIKE` 검색만 |

## 신뢰 경계 `확인됨`

```
┌─────────────────────────────────────────────┐
│  신뢰하지 않음                                │
│  ─ 브라우저에서 오는 모든 입력                  │
│  ─ 업로드 파일의 Content-Type                 │
│  ─ 클라이언트의 CAPTCHA 통과 주장               │
└─────────────────────────────────────────────┘
                    │
                    ▼  (검증 지점)
┌─────────────────────────────────────────────┐
│  애플리케이션 내부                             │
│  ─ @Valid, 도메인 권한 판정, DB 제약            │
└─────────────────────────────────────────────┘
                    │
                    ▼
┌─────────────────────────────────────────────┐
│  신뢰함                                      │
│  ─ PostgreSQL (같은 네트워크)                 │
│  ─ SMTP·CAPTCHA 제공자 응답                   │
└─────────────────────────────────────────────┘
```

업로드 파일의 `Content-Type`은 "신뢰하지 않음"에 있어야 하는데
**저장 시점에는 그대로 믿습니다** (`FileStorageService.java:58-66`). `미결정`
